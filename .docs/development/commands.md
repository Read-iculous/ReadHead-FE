# Development Commands — ReadHead-FE

## Common Commands Reference

| Command | Purpose |
|---|---|
| `pnpm run dev` | Starts Vite HMR dev server for Web Portal & Extension |
| `pnpm run build` | Builds production-optimized artifacts to `dist/` |
| `pnpm run build:extension` | Packages Chrome Extension into `dist-extension/` |
| `pnpm run build:web` | Builds standalone Web Portal into `dist-web/` |
| `pnpm run preview` | Previews production build of Web Portal locally |
| `pnpm run test` | Runs Vitest unit & component test suite |
| `pnpm run test:watch` | Runs Vitest in interactive watch mode |
| `pnpm run test:coverage`| Generates code coverage report |
| `pnpm run lint` | Runs ESLint across all TypeScript & TSX files |
| `pnpm run format` | Runs Prettier to auto-format codebase |
| `pnpm run typecheck` | Validates TypeScript types without emitting code |
