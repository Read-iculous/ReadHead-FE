# Knowledge — Glossary

| Term | Definition |
|---|---|
| **BYOK (Bring Your Own Key)** | Architecture where users supply their own external AI provider credentials (Google Gemini, OpenAI, Claude). Keys are encrypted with AES-256-GCM on the backend. |
| **Side Panel** | Chrome's native split-screen UI surface introduced in Chrome 114+ (`chrome.sidePanel`), allowing an extension to stay open alongside web content. |
| **Shadow DOM** | A browser standard providing encapsulated DOM subtrees with private scoped CSS, preventing styles from leaking in or out. |
| **SSE (Server-Sent Events)** | An HTTP streaming protocol where a server pushes textual chunks over an open connection using `text/event-stream`. |
| **Bionic Reading** | A typographical reading technique that guides the eyes through text by highlighting the initial parts of words. |
| **OpenDyslexic** | An open-source typeface designed to mitigate some of the common reading errors caused by dyslexia. |
| **Dwell Time** | The duration a user spends lingering on a specific paragraph or section without scrolling, used as a cue for reading difficulty. |
| **PII (Personally Identifiable Information)** | Sensitive personal information (credit cards, IDs, passwords) subject to client-side pre-flight blocking. |
| **Groundedness** | The degree to which an AI-generated statement is directly supported by evidence extracted from the active reading material. |
